# Kintsugi Site Template

Astro site that renders the JSON content collection produced by `kintsugi render` into a static HTML site.

## Build

```bash
npm install
npm run build
```

`prebuild` runs `scripts/fetch-pr-data.mjs`, which uses `gh` to fetch PR state for each slice with `audience: upstream`. If `gh` is unavailable, the hook continues with empty PR data.

## Configuration

- `BASE_URL` — site base path (defaults to `/`). Set to `/chunks/` to embed under a parent site.
- `SITE_URL` — canonical URL for absolute links (defaults to `http://localhost`).

## Content

The site reads JSON from `src/content/`:

- `manifest-meta.json` — repo metadata
- `dag.json` — node/edge graph for the DAG view
- `slices/<id>.json` — one file per slice
- `pr-data/<id>.json` — per-slice PR state from `gh` (generated by prebuild)

For development, fixture files are committed in `src/content/`. Real deployments overwrite these with output from `kintsugi render` against the target repo.
